VOIX

Your personal AI language tutor. It corrects your grammar, upgrades your vocabulary, and explains why — not just what.

View the source How the correction works

Grammar correction runs on the device

lib/data/services/grammar_engine.dart is a rule engine covering the mistakes learners actually make: subject–verb agreement with irregular and -ies/-es forms, tense after did, articles by vowel sound, uncountable nouns, double negatives, double comparatives, and a set of common Indian-English idioms.

Running locally is what makes real-time correction viable — there is no round trip between finishing a sentence and seeing the fix. Rules are ordered most-specific-first and each span is corrected at most once, so overlapping rules cannot produce contradictory advice. When several rules fire, each contributes its own explanation but they share one fully-corrected sentence.

Both directions have to hold

  • Fix
    Did you went go there?

    “Did” already marks the past, so the next verb stays in its base form.

  • Fix
    I have a doubt question

    For a question in class or a meeting, English uses “question”. “Doubt” means you do not believe something.

  • Keep
    I doubt it will rain

    Scoped tightly. “I doubt it” is perfectly correct English and must not be flagged.

  • Keep
    everyday English

    “Everyday” (one word) is an adjective. Flagged only when no noun follows, so this is left alone.

The visuals are vectors, not assets

The splash orb, the VOIX mark, the waveform, every chart and the level badge are CustomPainters. The app ships no raster art beyond the launcher icon, so it stays crisp at every density and the mark can animate its own stroke.

The aurora backdrop deliberately avoids BackdropFilter: it paints three oversized radial blooms into one layer. Stacked blur filters are the usual reason a dark gradient UI drops frames on mid-range Android.

Voice degrades, never blocks

SpeechService guards every platform call. No recogniser, a denied permission, or a plain emulator all resolve to the same outcome: the conversation screen switches to typed input and says why. The core feature is never unreachable.

Colours are a ThemeExtension, so widgets read context.colors.textSecondary and get the right value for the active brightness without branching. Motion is 160 / 260 / 420 ms — short on purpose.

Run it

No backend, no API keys, no config files. Requires Flutter 3.35+ (Dart 3.5+).

$ git clone https://github.com/nagachaitanyanagachaitanya695-dot/voix
$ cd voix
$ flutter pub get
$ flutter run

Check it

The widget tests use a tall surface and repeated pumps rather than pumpAndSettle — the aurora and orb animate forever by design, so the tree never quiesces.

$ flutter analyze   # 0 issues
$ flutter test      # 52 tests

Architecture

  • features → providers → data → core
  • Nothing points back up
  • AuthRepository and AiTutorService are interfaces with one wiring point each in lib/providers/app_providers.dart

Design tokens

  • Brand ramp #22D8F0 → #3B7BFF → #8B5CF6
  • Plus Jakarta Sans for UI, Manrope for figures
  • Motion 160 / 260 / 420 ms

Accessibility

  • OS text scaling honoured up to 1.3×
  • Semantic labels on icon buttons, charts, achievements and score rings
  • Cards size to a minimum height, so larger text grows the layout instead of clipping it
