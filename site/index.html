Every rule below is ported line for line from lib/data/services/grammar_engine.dart. Same patterns, same explanations, same one-correction-per-span ordering — running here in JavaScript instead of Dart.

The app runs this on-device, which is what makes correction real-time — there is no round trip between finishing a sentence and seeing the fix.

How it works

Three things worth knowing

01

Correction runs on the device

A rule engine covering the mistakes learners actually make: subject–verb agreement, tense after did, articles by vowel sound, uncountable nouns, double negatives, double comparatives, and a set of common Indian-English idioms. Rules are ordered most-specific-first and each span is corrected at most once, so overlapping rules cannot contradict each other.

02

The visuals are vectors, not assets

The splash orb, the VOIX mark, the waveform, every chart and the level badge are CustomPainters. The app ships no raster art beyond the launcher icon, so it stays crisp at every density and the mark can animate its own stroke.

03

Voice degrades, never blocks

SpeechService guards every platform call. No recogniser, a denied permission, or a plain emulator all resolve to the same outcome: the conversation screen switches to typed input and says why. The core feature is never unreachable.

Stack

Built with

Nothing points back up the dependency chain. Every screen reads state through Riverpod; no screen constructs a repository directly.

features→providers→data→core
Flutter 3.35Dart 3.5flutter_riverpod shared_preferencesspeech_to_textflutter_tts firebase_authcloud_firestoregoogle_sign_in flutter_local_notificationsweb_socket_channelrecord

Swappable seams

AuthRepository and AiTutorService are interfaces with a single wiring point each in lib/providers/app_providers.dart. Replacing the local implementation with Firebase or a hosted LLM is a one-line override — no UI change.

Design tokens

Colours are a ThemeExtension, so widgets read context.colors.textSecondary and get the right value for the active brightness without branching. Brand ramp #22D8F0 → #3B7BFF → #8B5CF6. Motion 160 / 260 / 420 ms.

Accessibility

OS text scaling honoured up to 1.3×, clamped so fixed-height chrome survives. Semantic labels on icon buttons, charts, achievements and score rings. Cards size to a minimum height, so larger text grows the layout instead of clipping it.
